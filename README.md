# 💜 LARP Exodus

### A 1:1 Exodus Wallet UI Recreation

**LARP Exodus** is an independent project that recreates the original **Exodus Wallet** interface with a strong focus on visual accuracy, interaction, and user experience.

The project aims to reproduce the familiar Exodus design as closely as possible, including its layout, navigation, wallet interface, and transaction workflow.

Whether you're exploring wallet interfaces, testing interactions, or experimenting with a simulated crypto wallet environment, LARP Exodus provides a familiar Exodus-inspired experience.

---

## ✨ Features

- 🎨 **1:1 UI Recreation** — A faithful visual recreation of the original Exodus Wallet interface.
- 💰 **Wallet Dashboard** — A familiar overview of wallet balances and assets.
- 🔄 **Transaction Simulation** — Create, display, and process simulated transactions.
- 🏷️ **Wallet Address Management** — Update wallet addresses through keyboard shortcuts.
- ⚡ **Keyboard Shortcuts** — Quick access to essential actions.
- 🖥️ **Desktop-Oriented Experience** — Designed to provide a familiar desktop wallet workflow.

## ⌨️ Keyboard Shortcuts

| Shortcut | Action |
|:---|:---|
| `Ctrl + A` | Create a new transaction |
| `Ctrl + A` (after transaction) | Display the transaction |
| `Ctrl + X` | Update wallet address |
| `Ctrl + S` | Process the last transaction / Mark as received |

## 🎯 Project Goals

The primary goal of LARP Exodus is to recreate the original Exodus Wallet experience as closely as possible.

The project focuses on:

- Maintaining visual consistency with the original interface.
- Reproducing familiar wallet interactions.
- Providing responsive and intuitive navigation.
- Creating a realistic simulated transaction workflow.
- Keeping the interface simple, familiar, and easy to use.
